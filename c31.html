第三章、计算机体系基础：主要知识点

计算机系统的抽象层次

计算机系统分层结构：硬件 → 微体系结构 → 指令集架构 → 操作系统 → 应用 → 用户。每层提供服务给上层，同时隐藏复杂实现，实现模块化、抽象化和可扩展性。

数字系统与转换

二进制、八进制、十六进制表示及与十进制的转换

（讲义，例题2.7）：

二进制数1011.01B转为十进制数

$$1011.01B=1 \times 2^3+0\times 2^2 +1 \times 2^1+1\times2^0+0\times 2^{-1}+1 \times 2^{-2} =11.25D$$

（讲义，例题2.8）：

八进制456.7Q转十进制

$$456.7Q=4 \times 8^2+5\times 8^1 +6 \times 8^0+7\times8^ {-1} =302.875D$$

数值数据、字符数据和多媒体数据的表示与存储

数据的单位： 1位(bit)：每个0或1，就是1位，缩写为b
字节Byte：连续8位（bit）为一个字节，缩写为B， 1B = 8b；字节是数据存储中最常用的基本单位
字（word）：计算机一次处理的数据位数，字长不是一个固定的数值，通常是8的整数倍，如8，16，32，64位。

机器数（机器码）：

把符号也转换成二进制位（0/1），这种 “符号 + 数值” 的二进制组合，就是机器数。符号位：机器数的最高位用来表示符号，约定：0 = 正数，1 = 负数； 数值位：剩下的位用来表示数字的绝对值的二进制。

（讲义，例题3.1-3.2）：

[+33]原=0010 0001；[--33]原=1010 0001；

正数x的补码[x]补和原码相同；
负数x的补码[x]补，等于其原码的符号位不变，数值位取反加1.

（讲义，例题3.6）：

字长为8位，求[50--30]_补

答:00010100

浮点数

用于表示和计算实数的重要数据类型，尤其适用于科学计算和工程应用。它通过科学记数法的方式，将实数分解为尾数和指数，在计算机中以二进制的形式存储

整数（Integer） 二进制表示 无符号整数（Unsigned）：直接二进制编码

有符号整数（Signed）：常用 补码表示 正数：原码 = 补码 负数：补码 = 原码取反 + 1


补码的算术移位

将[x]补的符号位和数值一起右移一位，可实现除法功能（除以2）。对于带符号的定点补码整数，除以2时应使用算术右移，以确保符号位的正确性。而对于无符号数，则可以使用逻辑右移。
例如：-6 的二进制补码表示: 1111 1010
算术右移一位后： 1111 1101 = -3 (正确)
逻辑右移一位后： 0111 1101 = 125 (错误，符号位丢失)

逻辑移位

逻辑移位将操作数当做无符号数看待，规则：逻辑左移时，高位丢失，低位舔0，逻辑右移时，地位丢失，高位舔0

补码加减法运算

[A+B]补=[A]补+[B]补
[A-B]补=[A]补+[--B]补

定点数的乘法运算

在计算机中，乘法运算由累加和右移操作实现，又分为原码一位乘法和补码一位乘法。右移操作为逻辑右移

定点数的除法运算

除法运算可转换成“累加--左移”（逻辑左移），又分为原码除法运算；补码除法运算

存储方式 固定长度（如 8 位、16 位、32 位、64 位）


注意：8(bit)位是一个字节(byte)，计算机内存习惯于用字节作为单位，而不是用位，例如1KB就是1千字节（十进制）；1024位称为：1千比特 Kb或Kbit

实数（Floating-Point，浮点数：定义，带小数的数，如1.2；-0.001；结构：符号位+指数位+尾数位） IEEE 754 标准表示（常用单精度 32 位、双精度 64 位） 组成：符号位 S（1 位）+阶码 E[指数位]（8 位单精度）+尾数（小数部分）M（23 位单精度）

字符数据就是表示文字、符号或字母的数据

ASCII（American Standard Code for Information Interchange）码是一种用于表示字符的编码标准，它将字母、数字、符号等字符映射为数字，通常使用7位二进制表示（可以扩展为8位）。ASCII码值的大小遵循一定的规律，特别是在字符类型的顺序中。以下是一些主要的规律：

ASCII值大小的规律：


数字字符（'0' 到 '9'）的ASCII值范围是 48 到 57。
大写字母（'A' 到 'Z'）的ASCII值范围是 65 到 90。
小写字母（'a' 到 'z'）的ASCII值范围是 97 到 122。
控制字符和符号的ASCII值分别分布在 0 到 31 和 32 到 47 以及 58 到 64 之间。
小写字母的ASCII值比大写字母大 32。

单字符（Character），定义：计算机存储的单个字符，如 'A'、'中'

存储方式： ASCII 编码：英文字符，占 1 个字节（8 位） Unicode 编码（UTF-8、UTF-16 等）；用途：用来处理文本、标识符、符号等。

基本逻辑运算

与（AND，∧）; 或（OR，∨）；非（NOT，¬）；异或（XOR，⊕）；同或（XNOR）；

布尔代数的基本定律（重点）

单位元（恒等律）

$$ \begin{align} A+0=A \\ A\cdot 1=A \end{align} $$

互补律

$$ \begin{align} A+\bar {A}=1 \\ A\cdot \bar {A}=0 \end{align} $$

交换律

$$ \begin{align} A+B=B+A \\ A\cdot B=B\cdot A \end{align} $$

分配律

$$ \begin{align} A+(B\cdot C)=(A+B)\cdot(A+C) \\ A\cdot (B+C)=(A\cdot B)+(A\cdot C) \end{align} $$

常用定律

名称 与形式或形式
同一律 $$A\cdot A=A$$ $$A+A=A$$
零元律 $$A\cdot 0=0$$ $$A+1=1$$
吸收律 $$A\cdot (A+B)=A$$ $$A+(A\cdot B)=A$$
结合律 $$A\cdot (B\cdot C)=(A\cdot B)\cdot C$$ $$A+(B+C)=(A+B)+C$$
德摩根定理 $$\overline {A\cdot B}=\overline {A}+\overline {B} $$ $$\overline {A+B}=\overline {A}\cdot \overline {B}$$

最小项

⼀个包含所有n个变量的乘积项（与项），每个变量以原变量或反变量的形式出现且仅出现⼀ 次。每个最⼩项对应真值表中唯⼀空格

掩码（Mask）

使⽤⼀个掩码，希望复位的位设为0，其他位设为1，然后与原数进行与运算

逻辑门

半加器：逻辑表达式：$$ \begin{align} S=A\otimes {B}\\ C=A\cdot B \end {align} $$

全加器

逻辑表达式：$$ \begin{align} S=A\otimes {B}\otimes {C_{in}}\\ C=(A\cdot B)+(C_{in}\cdot (A\otimes{B})) \end {align} $$

冯·诺依曼架构（Von Neumann Architecture）

是一种经典计算机体系结构模型，其核心思想是 程序和数据统一存储，并由 CPU 按顺序执行指令。
由五个基本部件组成： 运算器（ALU） 控制器（CU） 存储器（Memory） 输入设备（Input） 输出设备（Output） 其中，运算器和控制器共同构成 中央处理器（CPU）。

CPU（Central Processing Unit，中央处理器）

是计算机的核心部件，负责 执行程序指令、进行数据运算，并控制和协调计算机各部件的工作。主要由以下两部分组成： 运算器（ALU）：完成算术运算和逻辑运算； 控制器（CU）：负责取指、译码并发出控制信号。 此外，CPU 内部还包含 寄存器，用于暂存指令和数据。
主要功能 取指并执行指令 完成算术与逻辑运算 控制程序执行流程 协调存储器与 I/O 设备工作

控制器（Control Unit，CU）

是 CPU 的核心组成部分之一，负责 指挥和协调计算机各部件按照指令要求有序工作。


主要功能 取指令 从主存中取出下一条指令送入指令寄存器。 指令译码 分析指令的操作类型和操作数信息。 产生控制信号 向运算器、存储器和 I/O 设备发出控制信号。 控制执行过程 协调各部件完成指令执行的各个步骤。 控制程序流程 管理程序计数器，处理顺序执行、转移和中断。

控制器的基本组成

程序计数器（PC） 存放下一条将要执行的指令地址，用于控制指令执行顺序。 指令寄存器（IR） 存放当前正在执行的指令，供译码和控制使用。 指令译码器（ID） 对指令寄存器中的指令进行分析，确定操作类型和控制需求。 时序控制电路 产生各操作步骤所需的时序信号，保证各部件按正确顺序工作。 控制信号发生器 根据译码结果和时序信号，向运算器、存储器和 I/O 设备发出控制信号。

主存储器（内存）（Main Memory）

主存储器（又称 内存、RAM，即 随机存取存储器）是计算机系统中的一个重要组成部分，主要用于存储正在运行的程序和数据。它与 中央处理器（CPU） 直接连接，提供高速的读写访问，支持 CPU 快速获取所需数据和指令。

内存的层次结构: 将高速的小容量存储（如寄存器、缓存）与大容量、较慢的存储（如硬盘、SSD）结合起来，提升整体系统效率。

地址空间：所有可寻址内存单元的总数

（内存）存储容量：能存放二进制代码的字节总数。

$$ \color{red} 存储容量（存储器）=存储单元个数\times 存储字长/8 $$

（注：（内存）存储容量以字节Byte为单位，1个字节=8位bit，1字节是计算机存储的最小单位）

按字节编址（Byte Addressing）

编址（Addressing）：给"存储单元"分配地址的方式，用于 CPU 定位内存中的数据。

按字节编址是计算机主存储器的一种编址方式，指的是：内存中每一个字节都有一个唯一的地址，

按字节编址： 主存储器以 1 字节（8 bit） 作为最小可编址单位， 每个字节对应一个独立的内存地址。

一个“字”占多个连续地址；如果： 字长 = 32 位 = 4 字节 那么一个字需要 4 个连续地址：

地址位数与内存容量直接相关 （常考）

若： 地址线为 n 位 按字节编址，则： 可寻址内存容量 = 2n 字节

存储单位二进制换算

  1. 1 B（字节，Byte）= 8 b (位，bit)
  2. 1 KB = 210 B = 1024 B
  3. 1 MB = 210 KB = 220 B
  4. 1 GB = 210 MB = 230 B

寻址位数计算公式

寻址位数 n 满足：2 n = 待寻址的总单元数

简单计算机模型Simple-1

程序执行：指令格式、机器周期（取指、译码、执行）、Simple-1模型机示例

指令格式（Instruction Format）

是指一条机器指令在存储器中的 二进制编码结构，规定了指令各字段的组成及其含义。
基本组成
一条指令通常由以下几部分构成：
操作码（Opcode）： 指明指令要完成的操作类型，如加、减、跳转等。操作码的位数决定可支持的指令数量；操作码示例（如 Add、Load、Jump）；操作码位数决定指令系统可表示的最大指令数量，例如：操作码位数为8，指令数是2^8=256
操作数地址字段（Operand）： 指明参与运算的数据或其存放位置。字段长度决定可寻址的内存范围；与操作码一起构成完整指令

机器周期（Machine Cycle）

是 CPU 执行一条基本操作（如取指、读写存储器）所需的 最短时间单位，通常以时钟周期为基础。
机器周期通常包括以下步骤： 寻址（Addressing）：将存储单元地址送到地址总线 读/写（Read/Write）：从存储器读入或写出数据 数据传送（Data Transfer）：数据在总线上传输 执行（Execute）：CPU 执行运算或控制操作；一个指令可能需要 多个机器周期 才能完成

取指周期（Instruction Fetch Cycle）

是机器周期的一种，指 CPU 从存储器中取出下一条指令并送入指令寄存器（IR） 的过程。
主要步骤:
取指令地址 CPU 从程序计数器（PC）中获得下一条指令的存储地址。 将地址送到存储器 将地址放入地址总线，请求存储器提供指令数据。 读取指令 存储器将指令送到数据总线，CPU 接收指令。 存入指令寄存器 将取来的指令存入 IR，以便后续译码和执行。 更新程序计数器 PC 自动加 1（或跳转），指向下一条指令的地址。

示例程序 Simple-1


目标：AC=M[0]+M[1]


表示一条加法运算指令，其具体含义为三个核心部分：M 是 主存储器（Main Memory） 的缩写，方括号内的数字是存储单元的地址。M[0] 指地址为 0 的存储单元中存放的数据，M[1] 指地址为 1 的存储单元中存放的数据。AC 是 累加器（Accumulator） 的缩写，是 CPU 中一个专门用于临时存放运算数据和结果的寄存器。 在简单机中，累加器是算术运算的核心部件，几乎所有运算都需要通过它来完成。
整体运算逻辑 处理器执行该指令时，会依次完成以下三步操作： 从主存地址 0 中读取数据，送入运算器； 从主存地址 1 中读取数据，送入运算器； 运算器对两个数据执行加法运算，将最终结果写入累加器 AC 中。

地址 指令 说明
000000000LDA M[0]，AC = M[0]
101000001ADD M[1], AC +=M[1]
211100000HLT，程序结束

执行过程：

取指周期：CPU 从地址 0 取出 LDA 指令 译码：Opcode = 000 → LDA 执行：将 M[0] 内容送入 AC 更新 PC → 1 重复取指-译码-执行，直到 HLT
